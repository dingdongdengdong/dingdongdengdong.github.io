01 / System intent

A mobile platform where autonomy and manipulation meet a public-space task.

Eco-Rover frames collection as a systems problem: perceive the environment, navigate safely, decide on an interaction, and use a custom arm where physical handling is required.

The project report identifies Eco-Rover as a smart-city environmental management platform. This portfolio presents the Customarm as part of that integration story—not as a separate, unsupported repository claim.

It expands the portfolio’s embodiment range from fixed-arm learning and aerial inspection to a mobile, task-oriented robot system.
