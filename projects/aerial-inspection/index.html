01 / System objective

Build the integration path before presenting benchmark outcomes.

The repository is structured as an eight-milestone sim-to-real program, from synthetic data and baseline training through ROS2 integration, Jetson optimization, and a final physical demonstration.

Its current public evidence is strongest at the architecture, safety, mission, simulation-script, and contract-test levels. Targets such as dataset size, mAP, latency, and Jetson frame rate are acceptance criteria—not completed results.

This distinction is central to the case study: it shows how the work is decomposed and safeguarded without converting a roadmap into a success claim.

05 / 2026 development report

From simulated defect data to edge-assisted inspection workflow.

Data

Synthetic defect data

The report describes Isaac Sim Replicator use alongside SteelCrack and OmniCrack30K data sources for crack and corrosion model development.

Deployment path

Vision to edge device

YOLO and SegFormer comparison, Jetson Orin Nano inference, and staged camera validation are documented as development and evaluation work.

Physical workflow

Locate, mark, record

The intended system estimates defect location, approaches it with a two-axis manipulator, places a magnetic marker, and records the result in a dashboard.
