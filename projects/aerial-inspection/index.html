01 / System objective

Make every simulated crack traceable, visible, and independently checkable.

The pipeline replaces placeholder cube-shaped cracks with UV-mapped RGBA decals sourced only from the SteelCrack training split.

Each prepared texture records source ID, split, and hashes for the original, mask, and generated asset. The scene keeps the existing drone and overview camera paths while adding a 4.2 m frontal inspection view.

Every fifth frame is generated as a clean hard negative. RGB, semantic segmentation, camera parameters, projected binary masks, and manifests are checked as one evidence bundle.

Provenance

Train-only source boundary

Validation and test data, plus DACL10K, are excluded from texture selection and synthetic generation.

Rendering

Transparent decal geometry

The material graph uses RGB and alpha with an opacity threshold, so only crack pixels appear on the steel surface instead of a rectangular patch.

Labels

Two-mask cross-check

BasicWriter semantic output is compared with a homography projection of the original alpha mask, including exact and 1-pixel-tolerant IoU.

04 / Validation path

The first 5,000-frame run failed—and the final dataset records the fix.

Passed

100-frame smoke test

80 positive and 20 clean frames passed file, mask, size, split, and visual checks.

Rejected

First full run

Thin rotated crack pixels were clipped when large decals were viewed from roughly 3 m.

Corrected

Camera-distance gate

The generator now calculates the minimum 3–5 m distance needed to keep each rotated decal in frame.

Passed

5,000-frame v2

All 20,001 artifacts passed, with zero empty positive masks or invalid clean masks.

05 / Live perception

The repository also carries crack models into a browser-based camera loop.

Camera

C920 live stream

A WebSocket interface accepts browser camera frames, returns annotated JPEG results, and reports round-trip and display-rate metrics.

Model paths

Segmentation alternatives

The code includes a DACL10K crack/rust YOLO preparation path and an official OmniCrack30K nnU-Net ensemble interface.

Outputs

Auditable snapshots

Saved runs include originals, probability maps, binary masks, one-pixel centerlines, rendered overlays, and JSONL metrics.

06 / Evidence boundary

What the implementation proves—and what it does not.

Verified in the repository

  • Isaac Sim 5.1 full-streaming scene readiness
  • Traceable SteelCrack RGBA decal generation
  • 100-frame smoke test and 5,000-frame final dataset
  • Semantic-to-projected-mask alignment metrics
  • Live structural-crack segmentation service

Not claimed by this evidence

  • Performance on the held-out SteelCrack test split
  • Generalization to real crane imagery
  • Crack depth, severity, or structural strength
  • Engineering safety assessment or repair authority
  • Commercial redistribution rights for source data
