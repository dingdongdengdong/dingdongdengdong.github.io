01 / Problem

A custom embodiment breaks the assumptions of an off-the-shelf learning stack.

V2 combines a non-standard five-axis arm, a two-finger gripper, constrained orientation freedom, and hardware that does not yet expose a complete LeRobot-compatible control path.

The first engineering problem is therefore not policy training. It is creating a trustworthy path from human motion to bounded robot commands while keeping the robot model, joint limits, workspace, visualization, and future dataset schema consistent.

The project deliberately validates each boundary without motors first. Physical control remains blocked until motor model, CAN interface, joint signs, and zero offsets are verified.

01

Embodiment configuration

Joint limits, workspace, home pose, scale, and tool frames come from the V2 URDF contract. The yaw-180 configuration aligns the cable-safe neutral with J1 = 0.

02

Operator mapping

Grip acts as a clutch, trigger controls the gripper, controller pose supplies the end-effector target, and explicit reset and yaw controls avoid unsafe mirrored mappings.

03

Safety boundary

Soft start, velocity limiting, joint-limit margins, command divergence checks, a 0.5-second watchdog, and trip-state freezing sit ahead of the unfinished motor backend.

03 / Model and versions

The learning model stays; the robot contract evolves.

Echo Flow Lite is a compact project-specific LeRobot policy: two camera views and joint state are encoded into spatial tokens, and a transformer reconstructs short action chunks through flow matching.

The implementation uses a shared ResNet18 image encoder for the front and wrist cameras, adds camera identity, spatial position, and robot-state tokens, then predicts absolute joint-and-gripper actions with a flow-matching decoder.

The architecture is inspired by the LeHome Challenge 2026 solution, especially its flow-matching, AWR/RECAP, DAgger, and sim-to-real direction. It is not the complete LeHome, π0.5, or OpenPI system and contains no language model.
