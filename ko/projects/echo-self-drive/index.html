01 / 시스템 경계

로봇의 시각 셸은 물리 상태를 추종하며, 직접 물리를 제어하지 않습니다.

직접 구성한 차동구동 프록시가 충돌과 움직임을 제어하고, 보호된 Echo Full CAD 셸은 매 시뮬레이션 스텝 이후 측정된 PhysX 자세만 추종합니다.

런타임은 기존 Echo, VICA, SuperArm 소스 트리를 보존합니다. 파생 URDF와 USD 에셋이 원본 파일을 수정하지 않고 도로 장면에 필요한 물리 및 구성을 담당합니다.

명령은 ROS 2 /cmd_vel로 들어와 안전 명령 멀티플렉서를 거쳐 프록시를 구동합니다. 오도메트리, 관절 상태, TF, RGB, IMU, RTX LiDAR는 명시적인 센서 인터페이스로 유지됩니다.

03 / 시각 검증

보존한 검증 영상은 외부 동작과 로봇의 온보드 시야를 함께 보여줍니다.

04 / 전체 도로 검증

센서 입력을 우회하지 않고 코스를 완료해야 성공입니다.

조건 01

보행자 대기

보행자 조건에서 정지하고 경로가 열린 뒤에만 주행을 재개합니다.

조건 02

LiDAR 우회

장애물 대응은 미리 지정한 장면 좌표가 아니라 최신 RTX LiDAR ROS 측정값을 사용합니다.

조건 03

복합 노면

과속방지턱 2개, 우회전, 중앙이 볼록한 도로, 비포장 구간을 모두 통과합니다.

조건 04

종점 정지

바퀴 접촉 상태를 유지한 채 정지 명령을 확인하고 종점에 멈춥니다.

05 / 통합 로봇 구성

Nav2에 매니퓰레이션 제어권을 주지 않으면서 SuperArm + AmazingHand를 탑재합니다.

마운트

파생 물리 결합

파생된 SuperArm + AmazingHand 에셋을 전면 가로 프레임에 장착하되 이동 프록시만 주행 권한을 유지합니다.

인터록

주행 전 접이 자세

도로 실행기는 휠 명령 인터록을 해제하기 전에 팔을 주행용 접이 자세로 접습니다.

센서 분리

손목 D435i 범위 유지

손목 RGB, 정렬 깊이, IMU는 매니퓰레이션 검증에 사용하며 도로 주행은 차체 RGB와 RTX LiDAR를 사용합니다.

06 / 근거 경계

검증하지 않은 범주를 명시하기 때문에 근거가 더 강합니다.

보관된 근거로 검증됨

  • 원래 시작 위치에서 전체 도로 코스 완료
  • 보행자 정지 및 재출발
  • 센서로 확인한 RTX LiDAR 우회
  • 과속방지턱 2개 및 복합 노면
  • 건강한 접촉과 종점 정지 명령 확인

별도 범주 또는 미검증

  • 보관된 전체 도로 실행의 오류 주입 검증
  • 뷰포트 LiDAR 디버그 시각화 근거
  • 주행 중 파지 또는 매니퓰레이션 접촉
  • 실제 도로 Sim-to-Real 적용
  • 패키지 내부 Docker 이미지, 드라이버, NGC 인증 정보
