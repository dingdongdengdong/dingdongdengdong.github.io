01 / 시스템 목표

모든 시뮬레이션 균열을 추적하고, 확인하고, 독립 검증할 수 있게 합니다.

임시 큐브 형태의 균열을 제거하고 SteelCrack 학습 분할에서 가져온 UV 매핑 RGBA 데칼로 교체했습니다.

준비된 각 텍스처는 원본 ID, 데이터 분할, 원본·마스크·생성 에셋의 해시를 기록합니다. 기존 드론 및 전체 장면 카메라 경로는 유지하면서 4.2 m 정면 점검 시점을 추가했습니다.

매 5번째 프레임은 균열이 없는 음성 샘플(clean negative)로 생성합니다. RGB, 시맨틱 세그멘테이션, 카메라 파라미터, 투영 이진 마스크, 매니페스트를 하나의 근거 묶음으로 검사합니다.

출처

학습 데이터 전용 경계

검증·테스트 분할과 DACL10K는 텍스처 선택과 합성 데이터 생성에서 제외했습니다.

렌더링

투명 데칼 형상

재질 그래프가 RGB와 알파 채널, 불투명도 임계값을 사용해 사각형 패치가 아니라 균열 픽셀만 강재 표면에 표시합니다.

라벨

두 마스크 교차 검증

BasicWriter의 시맨틱 출력과 원본 알파 채널을 호모그래피로 투영한 마스크를 정확 픽셀 및 1픽셀 허용 IoU로 비교합니다.

03 / Replicator 시각 검증

Isaac Sim 크레인 환경부터 생성된 균열 예시까지 전체 파이프라인을 한눈에 확인합니다.

04 / 검증 과정

첫 5,000프레임 실행은 실패했고, 최종 데이터셋은 수정 과정을 기록합니다.

통과

100프레임 스모크 테스트

균열 포함 이미지 80장과 무결함 이미지 20장이 파일, 마스크, 크기, 데이터 분할, 시각 검사를 통과했습니다.

반려

첫 전체 실행

큰 데칼을 약 3 m 거리에서 촬영할 때 회전된 얇은 균열 픽셀이 잘렸습니다.

수정

카메라 거리 조건

회전된 전체 데칼이 화면 안에 들어오도록 3–5 m 범위의 최소 거리를 계산합니다.

통과

5,000프레임 v2

빈 균열 마스크나 비정상 무결함 마스크 없이 전체 20,001개 산출물이 통과했습니다.

05 / 실시간 인식

저장소는 균열 모델을 브라우저 기반 카메라 루프로도 연결합니다.

카메라

C920 실시간 스트림

WebSocket 인터페이스가 브라우저 카메라 프레임을 받아 주석 JPEG를 반환하고 왕복 지연 및 표시 속도를 보고합니다.

모델 경로

세그멘테이션 대안

DACL10K 균열·녹 YOLO 준비 경로와 공식 OmniCrack30K nnU-Net 앙상블 인터페이스를 포함합니다.

산출물

검증 가능한 스냅샷

원본, 확률 맵, 이진 마스크, 1픽셀 중심선, 오버레이, JSONL 지표를 실행별로 저장합니다.

06 / 근거 경계

구현이 증명하는 것과 증명하지 않는 것을 구분합니다.
