01 / 연구 방향

단순한 로봇팔 제작이 아니라, 사람의 시연에서 실제 로봇 행동까지 이어지는 제어 가능한 경로를 만듭니다.

학습 정책이 의미 있으려면 로봇 모델, 관측, 행동 정의, 명령 권한, 안전 상태가 모두 동일한 물리 시스템을 설명해야 합니다.

범용 로봇 학습 예제는 지원되는 로봇, 안정적인 카메라, 정의된 그리퍼, 준비된 데이터 인터페이스를 전제로 합니다. 이 연구는 Eco-Rover 전체 시스템 중 Customarm에 초점을 맞추며, 커스텀 로봇의 기구와 소프트웨어 인터페이스를 함께 확립하는 단계부터 시작합니다.

첫 목표는 의도적으로 좁게 설정했습니다. 큐브를 보고 접근하고, 감싼 뒤 5 cm 이상 들어 올려 0.5초 이상 유지합니다. 좁고 측정 가능한 과제를 통해 동기화 오류, 도달 불가능 자세, 약한 파지, 위험한 명령 전환을 막연한 ‘로봇 AI’ 표현 뒤에 숨기지 않습니다.

01

로봇 형태

URDF 관절·한계·툴 프레임·카메라 마운트·정책 차원을 하나의 버전 인터페이스로 관리합니다.

02

시연 데이터

시뮬레이션 전용 상태나 명령값이 아니라 로봇이 실제로 보고 측정한 값을 기록합니다.

03

학습

짧은 미래 행동을 예측하고 새로운 영상과 실측 관절 상태를 반복해서 반영합니다.

04

실물 배포

텔레오퍼레이션과 정책 명령을 모터 앞단의 단일 fail-closed 권한 경계에 둡니다.

02 / 하드웨어 확장

V1으로 전체 경로를 증명하고, 완료되지 않은 V2 실물 롤아웃을 과장하지 않은 채 로봇 인터페이스를 확장합니다.

V1 · 검증 기반3축 + AmazingHand

Quest 움직임을 IK와 안전 계층을 거쳐 J1/J2/J3로 전달하고, 전면·손목 RGB 영상과 AmazingHand 파지 명령을 네 번째 행동값으로 기록한 첫 동작 스택입니다.

  • DM 모터 3개의 실측 관절각
  • 가짜 손 상태를 만들지 않는 AmazingHand 명령
  • Quest 클러치·트리거·리셋·HOLD 동작
  • 15 Hz LeRobot 에피소드 기록기
V2 · 현재 개발5축 + 2지 그리퍼

V2는 학습 방향을 유지하면서 Damiao DM-J4340P 관절 5개와 Feetech STS3215 병렬 그리퍼로 로봇 형태를 확장합니다.

  • Placo IK용 arm_v2_yaw180_ik.urdf
  • 시각 URDF에는 그리퍼 기구 유지
  • 케이블 안전 중립 자세를 J1 영점에 맞춘 yaw-180
  • 실물 부호·게인·오프셋·그리퍼 범위 캘리브레이션 진행 중

03 / 텔레오퍼레이션과 안전

Quest와 학습 정책이 하나의 실물 연결을 동시에 차지하지 않도록 설계했습니다.

입력

WebXR 매핑

오른쪽 컨트롤러 자세가 말단 목표가 됩니다. Grip은 클러치, Trigger는 파지이며, 명시적인 home/HOLD 조작으로 추적 시작 시 의도하지 않은 이동을 막습니다.

제어

IK + 제한된 동작

목표는 작업공간, 관절 한계, 속도, 명령 편차, 워치독 검사를 통과합니다. 학습 모델은 CAN 모터에 직접 명령하지 않습니다.

안전 실패

대체보다 HOLD

상태·영상·청크·하트비트·제어 주기·연결이 유효하지 않으면 새 추종을 멈춥니다. TRIP은 사람이 원인을 확인한 뒤 해제합니다.

04 / 시연 데이터

데이터셋은 로봇이 본 것, 측정한 것, 수행하도록 요청받은 것을 같은 시간축에 기록합니다.

관측 / 영상전면 RGB + 손목 RGB

전면 영상은 전체 작업공간을, 손목 영상은 그리퍼와 물체의 근접 관계를 제공합니다.

관측 / 상태실측 관절 피드백

CAN 피드백을 로봇 상태로 사용합니다. 명령 자세를 이미 도달한 실측값처럼 관측에 복사하지 않습니다.

행동관절 목표 + 파지

V1은 J1/J2/J3와 파지를 기록하며, V2는 이를 팔 5축과 병렬 그리퍼 명령으로 확장합니다.

에피소드 품질동작·시야·리셋·결과

정지·가림·충돌·잘못된 리셋 에피소드는 폐기하거나 실패 데이터로 분리하며 좋은 시연으로 다시 표기하지 않습니다.

A

파이프라인 스모크

20 episodes

수집을 늘리기 전에 두 카메라, 실측 상태, 행동, 15 Hz 주기, 리셋, 저장 완료를 확인합니다.

B

첫 BC 후보

성공 시연 ≥100개

성공을 보장하는 숫자가 아닌 시작 목표입니다. 의도적인 복구와 실패도 이후 평가를 위해 보존합니다.

C

고정 평가

5 cm 이상 리프트 · 0.5초 유지

접근, 안정적 감싸기, 리프트, 유지, 물체 위치별 실패와 안전 HOLD/TRIP을 보고합니다.

D

실패 중심 개선

DAgger + simulation-only AWR

반복 실패 구간의 교정 데이터를 수집하고 고정 시드 평가가 퇴행 없이 향상될 때만 체크포인트를 승격합니다.

05 / Echo Flow Lite

범용 VLA의 이름만 바꾼 모델이 아니라, 이 로봇을 위해 작고 검증 가능하게 만든 플로 매칭 정책입니다.

LeHome Challenge 연구의 플로 매칭과 Sim-to-Real 방향을 참고하되, 현재 프로젝트가 실제로 구현하고 검증할 수 있는 범위로 축소했습니다.

학습 시 정답 행동 청크와 Gaussian noise를 임의의 플로 시간에서 섞고, Transformer가 데이터와 노이즈를 잇는 속도를 학습합니다. 추론 시에는 노이즈에서 시작해 Euler 적분 10단계로 행동 시퀀스를 복원합니다.

선택적인 success·progress head는 이후 어려운 예제 탐색과 시뮬레이션 AWR에 사용합니다. 없는 레이블은 만들어내지 않고 마스킹합니다. Echo Flow Lite에는 언어 모델이 없으며 LeHome·π0.5·OpenPI 전체 시스템을 구현한 것도 아닙니다.

06 / Simulation-to-Real 게이트

렌더링, 접촉, 학습 행동은 서로 다른 주장이고 각각 별도의 시험이 필요합니다.

01

구조 검증

URDF 계층, 관절, 한계, 질량, 충돌, 툴 프레임, 카메라 마운트가 의도대로 로드되는지 확인합니다.

근거: 모델 검사 + 설정 검증
02

기계적 검증

스크립트 제어기가 물체에 접근해 감싸고 들어 올린 뒤 안정적인 접촉을 유지합니다.

승격 목표: 20회 중 최소 18회 성공
03

데이터 검증

영상, 피드백, 행동, 타임스탬프, 리셋, 결과가 동기화되고 재생 가능한지 확인합니다.

근거: 20 에피소드 수집 스모크 + 검사
04

행동 검증

고정 물체 위치와 시드에서 동결된 정책이 안전 구간 퇴행 없이 성공하는지 측정합니다.

아직 주장하지 않음: V2 체크포인트 및 롤아웃 성공률

시뮬레이션 전용 상태실물 배포 관측에서 제외학습 입력이 실제 로봇에서도 존재하도록 유지

07 / 현재 상태

구현한 기반과 아직 진행 중인 연구를 분리해 표시합니다.

  • Quest 컨트롤러 및 핸드 트래킹 입력 경로
  • 좌표 변환, 클러치, 명시적인 HOLD 동작
  • URDF 기반 설정과 시뮬레이션 IK 워크플로
  • 듀얼 카메라 LeRobot 기록기와 수집 검증 게이트
