01 / 문제

커스텀 로봇 형태는 범용 학습 스택의 기본 가정을 벗어납니다.

V2는 비표준 5축 팔, 2지 그리퍼, 제한된 자세 자유도, 그리고 아직 완성되지 않은 LeRobot 호환 제어 경로를 결합합니다.

따라서 첫 번째 엔지니어링 문제는 정책 학습이 아닙니다. 로봇 모델, 관절 한계, 작업공간, 시각화, 향후 데이터셋 스키마의 일관성을 유지하면서 사람의 움직임을 제한된 로봇 명령으로 안전하게 변환하는 경로를 만드는 것입니다.

프로젝트는 모터 없이 각 경계를 먼저 검증합니다. 모터 모델, CAN 인터페이스, 관절 방향, 영점 오프셋이 확인될 때까지 실물 제어는 차단합니다.

02 / 시스템

WebXR 입력에서 안전 게이트를 거친 로봇 명령까지 하나의 경로로 연결합니다.

01

로봇 형태 설정

관절 한계, 작업공간, 홈 자세, 스케일, 툴 프레임은 V2 URDF 인터페이스에서 가져옵니다. yaw-180 설정은 케이블에 안전한 중립 자세를 J1 = 0에 맞춥니다.

02

조작자 매핑

Grip은 클러치, Trigger는 그리퍼 조작, 컨트롤러 자세는 말단 목표로 사용합니다. 명시적인 리셋과 yaw 조작으로 위험한 미러 매핑을 피합니다.

03

안전 경계

소프트 스타트, 속도 제한, 관절 한계 마진, 명령 편차 검사, 0.5초 워치독, 트립 상태 고정이 미완성 모터 백엔드 앞단에 위치합니다.

03 / 모델과 버전

학습 모델은 유지하고 로봇 인터페이스를 확장합니다.

Echo Flow Lite는 이 프로젝트를 위해 만든 경량 LeRobot 정책입니다. 두 카메라 영상과 관절 상태를 공간 토큰으로 인코딩하고, Transformer가 플로 매칭으로 짧은 행동 청크를 복원합니다.

전면·손목 카메라에는 공유 ResNet18 인코더를 사용하고, 카메라 구분·공간 위치·로봇 상태 토큰을 더한 뒤 플로 매칭 디코더가 관절과 그리퍼의 절대 명령을 예측합니다.

LeHome Challenge 2026 솔루션의 플로 매칭, AWR/RECAP, DAgger, Sim-to-Real 전략을 설계 참고로 삼았습니다. 다만 LeHome·π0.5·OpenPI 전체 모델을 구현한 것은 아니며 언어 모델도 포함하지 않습니다.

V1

3축 + AmazingHand

첫 번째 구성은 두 RGB 영상과 실측 관절각 3개를 입력받아 J1/J2/J3와 AmazingHand 그립 명령을 예측합니다.

CORE

Echo Flow Lite

공유 듀얼 카메라 인코더, 공간·상태 토큰, Transformer, 플로 매칭 행동 디코더를 공통 학습 구조로 유지합니다.

V2

5축 + 2지 그리퍼

현재 버전은 DM-J4340P 구동기 5개와 STS3215 병렬 그리퍼를 사용합니다. Placo에는 arm_v2_yaw180_ik.urdf를 사용하고, 시각화에는 원본 그리퍼 모델을 유지합니다.

04 / 엔지니어링 근거

완성된 정책이 아니라 측정된 동작을 제시합니다.

제약결정이유
자세 자유도가 제한된 5관절단순한 접근 형상의 작업부터 시작임의 손목 자세가 필요한 작업을 피함
WebXR은 보안 컨텍스트가 필요자체 서명 로컬 HTTPS브라우저 기반 헤드셋 접근 유지
모터 인터페이스 미검증안전과 IK를 로컬에 유지하고 모의 백엔드 사용소프트웨어 진행이 실물 안전 준비 완료로 오해되지 않도록 함

05 / 상태

현재 동작하는 것과 아직 동작하지 않는 것을 구분합니다.
