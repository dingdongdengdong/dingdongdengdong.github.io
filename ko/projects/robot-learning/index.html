01 / 문제

커스텀 로봇 형태는 범용 학습 스택의 기본 가정을 벗어납니다.

이 로봇은 비표준 5관절 팔, 덱스터러스 핸드, 제한된 자세 자유도, 그리고 아직 완성되지 않은 Le로봇 호환 제어 경로를 결합합니다.

따라서 첫 번째 엔지니어링 문제는 정책 학습이 아닙니다. 로봇 모델, 관절 한계, 작업공간, 시각화, 향후 데이터셋 스키마의 일관성을 유지하면서 사람의 움직임을 제한된 로봇 명령으로 안전하게 변환하는 경로를 만드는 것입니다.

프로젝트는 모터 없이 각 경계를 먼저 검증합니다. 모터 모델, CAN 인터페이스, 관절 방향, 영점 오프셋이 확인될 때까지 실물 제어는 차단합니다.

02 / 시스템

WebXR 입력에서 안전 게이트를 거친 로봇 명령까지 하나의 경로로 연결합니다.

→
안전속도, 마진, 워치독

로봇모터 백엔드 미완료

01

로봇 형태 configuration

관절 한계, 작업공간, 홈 자세, 스케일, 툴 프레임을 여러 곳에 중복하지 않고 등록된 URDF에서 하나의 설정으로 생성합니다.

02

조작자 매핑

Grip은 클러치, Trigger는 그립, 컨트롤러 자세는 말단 목표로 사용합니다. 명시적인 리셋과 yaw 조작으로 위험한 미러 매핑을 피합니다.

03

안전 boundary

소프트 스타트, 속도 제한, 관절 한계 마진, 명령 편차 검사, 0.5초 워치독, 트립 상태 고정이 미완성 모터 백엔드 앞단에 위치합니다.

03 / 엔지니어링 근거

완성된 정책이 아니라 측정된 동작을 제시합니다.

제약결정이유
자세 자유도가 제한된 5관절단순한 접근 형상의 작업부터 시작임의 손목 자세가 필요한 작업을 피함
WebXR은 보안 컨텍스트가 필요자체 서명 로컬 HTTPS브라우저 기반 헤드셋 접근 유지
모터 인터페이스 미검증안전과 IK를 로컬에 유지하고 Mock 백엔드 사용소프트웨어 진행이 실물 안전 준비 완료로 오해되지 않도록 함

04 / 상태

현재 동작하는 것과 아직 동작하지 않는 것을 구분합니다.

  • Quest 컨트롤러 및 핸드 트래킹 입력

  • URDF 기반 설정과 IK
  • 대시보드와 가상 로봇 시각화

  • Le로봇 episode collection on the final embodiment
  • ACT 또는 VLA 학습과 실물 정책 평가
